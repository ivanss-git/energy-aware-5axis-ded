# Energy-Aware 5-Axis DED Process Planning

Undergraduate research project focused on developing an automated process-planning system for five-axis hybrid directed energy deposition.

The system will:

* Interpret five-axis toolpaths and component geometry
* Detect relevant geometric and orientation changes
* Apply physics-based process relationships
* Adapt laser power and powder flow
* Generate energy-aware G-code and M-code
* Visualize and validate the resulting process plan

## Current Status

Initial MATLAB project structure and mock-data pipeline under development.
